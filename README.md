# 言语1000词

面向公务员考试言语理解的移动端高频词记忆工具。手机优先设计，数据全部保存在本机浏览器中，无需注册登录。

## 主要功能

- **词库学习**：按教材篇章（成语篇 / 实词篇）与二级分类浏览、分组学习，支持词条详情与原文例句。
- **FSRS 间隔重复**：复习计划由 [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs) 算法自动调度，到期与逾期数量在首页展示。
- **分类辨析训练**：从已审核通过（`approved`）的近义词辨析题中按分类与题量抽题，逐题作答并即时给出判定与题目自带解析，训练结束后可查看成绩与逐题回看。中途退出可回来继续。
- **真题训练**：204 道公务员考试言语理解真题，可按篇章 / 年份 / 题型 / 题量组卷，答题后给出成绩单与逐题回顾。
- **学习统计**：学习总量、每日新学、复习趋势等本地统计。
- **数据备份与恢复**：一键导出完整 JSON 备份，可从备份文件校验并恢复。

底部导航包含：首页 / 学习 / 词库 / 统计 / 设置。「分类辨析」「真题训练」「辨析题库管理」通过首页卡片与设置页进入。

> 「辨析题库管理」（`/quiz-admin`）是题目生成与人工审核界面。新生成的题目一律为「待审核」，**不会自动通过**；只有人工审核通过的题才会进入训练。

## 正式数据文件位置

| 数据 | 源文件 | 运行时路径（构建后） |
|---|---|---|
| 正式词库（993 条记录，去重后 990 个词） | `data/vocabulary_final.json` | `public/data/vocabulary_final.json` → `/data/vocabulary_final.json` |
| 正式真题（204 道） | `data/exam_questions.json` | `public/data/exam_questions.json` → `/data/exam_questions.json` |

两处内容保持一致，`data/` 为整理归档，`public/data/` 为实际随构建发布并被打入 Service Worker 预缓存的部分。**这两个文件是 App 运行必需数据，不可删除。**

辨析题不存放在 JSON 中，而是在运行时由词库现场生成后写入浏览器 IndexedDB，经人工审核后使用。

## 本地存储说明

所有数据保存在浏览器 **IndexedDB**（数据库名 `yanyu-1000`，版本 2），共六张表：

`words`（词语）、`progress`（FSRS 学习进度）、`logs`（复习流水）、`quiz_questions`（辨析题）、`training_records`（训练作答记录）、`training_sessions`（训练会话）

用户设置（每日新词数、目标记忆保持率）保存在 `localStorage`。

关键特性：

- **数据不会自动上传云端**，本项目不包含服务端、账号系统或任何网络同步逻辑。
- **不同设备之间不会自动同步**。在手机和 iPad 上分别打开，是两个相互独立的数据集。
- 清除浏览器数据、卸载 PWA 或使用无痕模式，都可能导致本地数据丢失。建议定期导出备份。
- App 会尝试向浏览器申请持久化存储权限；即使获得授权，仍建议保留独立备份。

## 本地备份导出与恢复

入口：**设置 → 数据备份**。

- **导出**：生成包含全部六个数据表与用户设置的完整 JSON 文件，文件名形如 `言语1000词备份_YYYYMMDD-HHmm.json`。导出为只读操作，不修改任何现有数据。
- **恢复**：选择备份文件后，会先做格式与字段校验并向你展示内容摘要，确认后才写入。恢复为**整体覆盖，不与现有数据合并**；写入前会自动再导出一份当前数据作为「恢复前存档」（`言语1000词_恢复前存档_YYYYMMDD-HHmm.json`），避免误覆盖后无法回退。校验不通过或写入中途失败时，数据库保持原状。

## 部署到 Vercel

纯静态部署，无需服务端与环境变量。

| 配置项 | 值 |
|---|---|
| Framework Preset | Vite（自动识别） |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install` |

根目录的 `vercel.json` 已配置 SPA 重写规则，使直接访问 `/quiz`、`/exam`、`/settings` 等深层路径时返回 `index.html` 而不是 404；已存在的静态文件（JS/CSS/JSON/图标等）由文件系统优先命中，不受影响。

部署后需使用 HTTPS 访问，否则 Service Worker 不会注册、PWA 无法离线使用。

## iPhone 添加到主屏幕

1. 用 **Safari** 打开部署后的网址（Chrome 等第三方浏览器无法添加标准 PWA）。
2. 点击底部「分享」按钮。
3. 选择「添加到主屏幕」，确认名称后点「添加」。
4. 从主屏幕图标启动即为全屏无地址栏模式（`display: standalone`，锁定竖屏）。

首次打开后建议联网加载一次，让 Service Worker 完成缓存；之后可离线使用。
